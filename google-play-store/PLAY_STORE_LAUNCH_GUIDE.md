## 2. 💰 인앱 상품(In-App Product) 등록 (구글 플레이 콘솔)

1. **Google Play Console** 접속 ➔ 앱 선택
2. 좌측 메뉴 [수익 창출] ➔ [인앱 제품] ➔ **[제품 만들기]** 클릭
3. 아래 정보 입력:
   - **제품 ID**: `remove_ads_3300` ⚠️ (코드와 정확히 일치해야 함)
   - **이름**: 평생 광고 제거 (Ad-Free VIP)
   - **설명**: 명심코칭 앱 내 모든 배너 및 전면 광고를 영구적으로 제거합니다.
   - **기본 가격**: **₩3,300** (세금 포함)
4. **[저장]** 후 **[활성화]** 클릭!

## 3. 📢 Google AdMob (광고 수익화) 설정

1. **AdMob 콘솔** 접속 ➔ 앱 추가 (Android)
2. 앱 ID 발급 후 `android/app/src/main/AndroidManifest.xml`의 `APPLICATION_ID`에 입력
3. 배너 광고 단위 및 전면 광고 단위 생성 후 코드에 적용 (현재는 테스트 ID로 안전하게 작동 중)

## 4. 🚀 안드로이드 스튜디오에서 AAB(앱 번들) 생성 방법

1. **Android Studio** 실행 ➔ `Open` 클릭 ➔ `c:/Users/aaccd/Downloads/ux/myeongsim-report/android` 폴더 선택
2. 상단 메뉴 [Build] ➔ **[Generate Signed Bundle / APK...]** 클릭
3. **[Android App Bundle]** 선택 후 Keystore(서명 키) 선택
4. 생성된 `.aab` 파일을 구글 플레이 콘솔 [프로덕션] ➔ [새 버전 만들기]에 업로드하면 배포 완료!
